# 🚀 Getting Started

Exon CLI is designed to get you from a blank terminal to a fully-functioning, production-ready Express.js API in less than a minute. Let's install the CLI tool and build your first application.

---

## 📦 Installation Options

Exon CLI can be executed directly without installation using `npx` (highly recommended to ensure you always use the latest version) or installed globally on your machine.

<CodeGroup>
```bash npx (Recommended)
# Run once to instantly scaffold your backend:
npx exon-cli create my-api
```

```bash Global Installation
# Install globally on your local system:
npm install -g exon-cli

# Scaffold projects using the global command:
exon-cli create my-api
```
</CodeGroup>

---

## 🛠️ Step-by-Step Project Scaffolding

Follow these simple steps to customize your new backend service using Exon's interactive CLI prompts.

<Steps>
  <Step title="Initialize the CLI Creator">
    Open your terminal, navigate to your desired directory, and start the project builder:
    
    ```bash
    npx exon-cli create my-express-api
    ```
  </Step>

  <Step title="Select Your Technology Stack">
    The interactive console will ask you to customize your server architecture:
    
    1. **Choose Programming Language**: Select between `TypeScript` (pre-configured strict checking) or `JavaScript` (ES Module format).
    2. **Choose Database ORM/ODM**: Pick `Prisma`, `Drizzle`, `Mongoose` (MongoDB), or `None` if you are building a database-less utility.
    3. **Enable Container Support**: Toggle `Docker` to generate immediate, optimized container structures.
  </Step>

  <Step title="Automatic Scaffolding & Dependency Merging">
    Exon CLI will now work its magic:
    *   Creates a workspace matching your selected language.
    *   Injects specific database connection helpers and pre-designed models.
    *   Generates optimized container files (`Dockerfile`, `docker-compose.yml`) if selected.
    *   Aggregates and resolves package dependencies (`package.json`).
    *   Automatically runs `npm install` to download dependencies cleanly.
  </Step>

  <Step title="Run Your Express Development Server">
    Navigate into your newly created project folder and launch the hot-reloading development server:

    ```bash
    cd my-express-api
    npm run dev
    ```

    By default, your server will boot up and listen for requests at:
    
    ```txt
    http://localhost:3802
    ```
  </Step>
</Steps>

---

## 🔍 Verifying the Setup

To verify that your new backend application is fully operational:

1.  **Check Status Endpoint**: Send a `GET` request to `http://localhost:3802/status` (or your configured root route) to verify that the Express app is running smoothly.
2.  **View Swagger Docs**: If you enabled the **Swagger** plugin, open your browser and navigate to:
    
    ```txt
    http://localhost:3802/docs
    ```
    
    You should see the interactive Swagger UI showing all pre-configured REST API routes ready for manual testing.
3.  **Inspect Environment Variables**: Review the newly created `.env` file to configure port values, database connection credentials, and logger profiles.
