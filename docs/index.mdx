# ⚡ Express Generator for Modern Node.js APIs

Welcome to the official documentation for **Exon CLI**, the premium, zero-config **Express generator** and TypeScript API scaffolding engine. 

Exon CLI is designed for developers who are tired of spending hours manually configuring environments, transpilers, containers, databases, and logging. It is a modern, extensible replacement for the legacy `express-generator` CLI, built from the ground up to follow modern enterprise architecture best practices.

## ⚡ What Makes Exon Unique?

Unlike simple boilerplates that become stale quickly, Exon CLI utilizes a **decoupled plugin architecture**. This allows you to scale your application's tech stack incrementally by adding or removing features dynamically via the terminal.

```bash
# Generate a new project in seconds
npx exon-cli create my-api

# Dynamically add features as your project grows
npx exon-cli add swagger
npx exon-cli add docker
```
